# NETSOL internship

Voice Coach is the current NETSOL internship project: a workplace communication coach for software developers and AI/ML engineers.

The learner practises with a simulated client, project manager, IT manager or HR representative, then receives feedback, an improved explanation and another attempt at the same situation. The objective is clear, confident and respectful communication with audiences who have different technical familiarity.

Read the [current PDF documentation and research report](Voice_Coach/output/pdf/Voice_Coach_Project_Plan.pdf). Phase 1 now has a Python / FastAPI prototype for one project-manager coaching cycle. See the [run guide](Voice_Coach/README.md) and [verification status](Voice_Coach/docs/PHASE_1_VERIFICATION.md).
